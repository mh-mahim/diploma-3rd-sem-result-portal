# Diploma 3rd Semester Result Portal - Project Guidelines

## Stack & Standards
- **Framework**: High-performance Single Page Application (HTML5, Modern CSS, Tailwind CSS, Vanilla ES6+).
- **Zero-Dependency Core**: Bundled data with client-side reactive rendering so the website functions instantly on GitHub Pages, Vercel, or local browser without requiring a backend runtime.
- **Design Tokens**: Slate / Indigo / Emerald / Amber / Rose color system with custom fonts (Inter & Hind Siliguri for Bengali readability).
- **Responsive Standard**: Mobile-first design optimized for smartphone screens, tablets, and full desktops.
